# Лабораторная работа 1

## Задание

Вариант 15. Отцентрировать блок текста и изображение внутри контейнера: с использованием Flexbox и абсолютного позиционирования текста и изображения. Изображение разместить в правом верхнем углу контейнера, обеспечить обтекание изображения текстом.

## Реализация

Разметка находится в `index.html`, стили - в `styles.css`. Контейнер использует `display: flex` и `position: relative`. Текст и изображение позиционируются абсолютно. Псевдоэлемент `::before` с `float: right` резервирует для обтекания область размером с изображение.

Версия демонстрирует размещение изображения в углу и обтекание.  оба дочерних элемента исключены из обычного потока. Минимальная высота контейнера — 360 px; при большом объёме текста содержимое может выйти за рамку.

## Запуск

1. Открыть `index.html` в браузере.
