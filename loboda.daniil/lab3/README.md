# Лабораторная работа №3

**Вариант 15, задача 3.** Реализовать функцию `moveZerosToEnd(arr)`, которая переносит все нули в конец массива и сохраняет порядок остальных элементов.

## Решение

Функция находится в `solution.js` и экспортируется по имени `moveZerosToEnd`. При первом проходе она добавляет в новый массив все элементы, отличные от числового нуля. При втором проходе добавляет нули. Исходный массив не изменяется.

## Примеры проверки

| Входной массив | Результат |
| --- | --- |
| `[0, 3, 0, 2]` | `[3, 2, 0, 0]` |
| `[1, 2, 3]` | `[1, 2, 3]` |
| `[0, 0]` | `[0, 0]` |
| `[]` | `[]` |
| `[0, '0', false, null, 2]` | `['0', false, null, 2, 0]` |

Сравнение `arr[i] === 0` отличает числовой ноль от строки `'0'`, `false` и `null`.
